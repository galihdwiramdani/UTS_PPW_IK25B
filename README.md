## Deskripsi
Website ini merupakan proyek Ujian Tengah Semester (UTS) mata kuliah Pemrograman dan Pengembangan Web (PPW). Website dikembangkan menggunakan PHP, HTML, CSS, dan JSON dengan fitur utama:

- **Login dan Logout** untuk autentikasi pengguna.
- **Register** untuk pendaftaran akun baru.
- **Session Management** untuk mengelola sesi login pengguna.
- **Halaman Home** sebagai halaman utama setelah login.
- **Penyimpanan Data Pengguna** menggunakan file JSON.
- **Styling CSS** untuk mengatur tampilan antarmuka website.
